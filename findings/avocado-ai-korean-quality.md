## 원인 추정

1. **외국 문자 섞임**: Llama 3.3 70B는 한국어 생성 중 한자어를 중국어 간체·번체로, 드물게 일본어·태국어로 바꿔 쓰는 알려진 경향이 있다 [추론]. 시스템 프롬프트가 영어이고 "Korean"만 지시하며, 후처리 검사가 없다(`generate.ts` `aiOutput`은 형태만 검증). 같은 입력 2회차에 섞임이 달라져 샘플링 변동이 큼. 개선 후보: 출력에서 `[぀-ヿ一-鿿฀-๿]` 검출 시 재시도 또는 경고, 한국어 시스템 프롬프트·"한자 금지" 명시, temperature 낮춤, 다른 모델 비교
2. **효능 빈칸**: 카페24·자체몰 상세 설명이 이미지라 `extractProductPage`가 얻는 텍스트에 효능이 없음. 프롬프트가 "없으면 빈 문자열"이라 지시대로 동작한 것. 사진 OCR(vision 모델)이나 사용자 안내 문구가 대안
3. **요금제·홈 페이지**: 효능 대신 요금·슬로건이 들어감. 입력 URL이 상품 상세가 아니라서 생기는 정상 범위의 오차
4. **사진 1장 이하**: `lib/product-page.ts`가 JSON-LD Product 이미지와 og:image만 모은다(본문 img 미수집). 앱스토어는 둘 다 잡히지 않아 0장
5. **장면 템플릿 문구·호출 대응**: 프롬프트가 장면 description의 의미(촬영 지시)를 설명하지 않아 모델이 key 이름을 직역 [추론]
6. **조사 오류**: 모델 출력에 조사 보정이 없음. 프로젝트에 `shared/josa`의 `withJosa`가 있으나 AI 출력에는 쓰이지 않음

## 한계

- 로컬 dev(Vite 플러그인)에서 Workers AI는 원격 바인딩으로 호출된다. 모델과 엔드포인트는 운영과 같지만, 페이지 가져오기는 내 PC 네트워크(한국 IP, 로컬 fetch)에서 나가므로 운영 Workers(Cloudflare 엣지 IP)에서는 403·지역별 응답이 다를 수 있다. 특히 쿠팡·올리브영처럼 봇 차단이 강한 곳은 이번 표본에서 뺐다
- 응답 시간은 로컬에서 원격 AI까지 왕복이라 운영 수치와 다르다
- 표본 7 URL × 2회로 작다. 외국 문자 섞임 비율(초안 10/14)은 방향만 보여 준다
- 초안 입력의 목적·규정은 가져오기 결과와 시드 기본 규정만 썼다. 실제 사용자가 목적을 직접 쓰면 결과가 달라질 수 있다
- 시드가 만든 데모 가이드 1건도 실제 모델로 초안이 생성됐지만 표본에는 넣지 않았다

## 개선 후 (TASK-066, 2026-10-27)

### 바꾼 것
- 문자 검사: `src/shared/script-check.ts`의 `foreignChars`. 한국어 기준은 한글·라틴·Common(숫자·문장부호·이모지)·Inherited(결합 문자)만 허용하고, 영어 기준(`lineEn`)은 한글도 걸러 낸다. 제품 이름·필수 문구처럼 사용자가 넣은 글자는 통과
- 재시도: `src/server/lib/ai.ts`의 `askUntilClean`. 섞이면 시스템 프롬프트에 "한글로만 쓰고 한자·일본어·태국 문자를 쓰지 마세요" 지시를 붙여 최대 2회 더 묻는다(`MAX_SCRIPT_RETRIES = 2`). 섞일 때마다 `[ai] 외국 문자 섞임 { attempt, chars }` 로그를 남긴다
- 끝까지 섞이면: 초안은 그 문장만 빼고, 가져오기는 그 칸만 비운다. 응답에 `scriptWarning: true`를 넣고, 기존 토스트로 "일부 문장을 다시 확인해 주세요" 류 안내를 띄운다
- 프롬프트: 두 기능 모두 "Korean text must use Hangul only" 명시. 목적 문구에 UGC·광고 소재 같은 용어를 쓰지 말라고 지시하고, 가져오기 예시를 "광고 소재용 UGC"에서 "제품을 직접 써 보는 후기 영상"으로 바꿈
- 내부 용어 후처리: 초안의 모든 한국어 필드에서 광고 소재·UGC·퍼포먼스 마케팅·전환 캠페인이 든 문장을 빼고, 목적 줄이 비면 기본 문장("○○을 직접 써 본 경험을 자연스럽게 보여 주세요.")으로 채운다. 가져오기 목적 제안에 나오면 비운다
- temperature: 이전에는 지정하지 않아 Workers AI 기본값(Cloudflare 모델 문서 기준 0.6)이었다. 초안 0.3, 가져오기 0.2로 낮춤. 초안은 장면 문구가 너무 단조로워지지 않게 0까지 내리지 않았다
